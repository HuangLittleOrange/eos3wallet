# 重新导入误删新密文：复现、修复和验证

日期：2026-10-18。处理 Hermes r4 第 20 轮的顺序恢复问题。开始时保存当前含未提交修改的 444 项来源文件哈希、待修改文件原件和 Git 状态；保留 r1–r4 独有源码与报告。仅使用生成的无资金 K1 测试密钥、内存存储和模拟网络；不读取真实钱包、密码、凭据，不广播交易。

## 原因

普通导入先为新 ID 保存并解密回读密钥，然后调用 `addWallet`。旧实现只按链、账户、公钥匹配重复记录，保留旧 ID，直接删除新 ID 密文，未确认旧槽能解密。旧索引存在但密文缺失、损坏或实际存着另一把钥匙时，导入可返回成功，留下不能签名的记录。最终实现自动修复缺槽；对已有异常密文采取保留并报错，避免把不一致记录里的其他恢复材料覆盖掉。

## 修复与提交顺序

`addWallet` 的加密导入调用现在携带本次密码，使用秘密写队列保护验证、密文修复、索引提交与临时副本清理。内部只用纯索引读取，不触发列表去重的队列重入。

1. 在当前密码代次解密主密码验证器及新密文，并从实际私钥派生公钥核对目标身份。密码失效、公钥不匹配或 ID 与其他身份冲突时拒绝，不清理密文。
2. 对重复记录保留最早 ID/创建时间并合并权限。旧槽缺失时，先登记存活 ID，再把经过验证的新密文复制到旧槽，并再次解密确认。已有的每份重复密文均须能解密并派生出目标公钥；旧槽损坏、错误私钥或无法验证时拒绝，原样保留新旧密文与索引，不自动覆盖。已有可用旧密文保持原样。当前 Envelope 不使用 ID 专属 AAD；缺槽复制在同一代次、同一密码内进行，不跨密码代次盲拷贝。
3. 提交索引后才清理不再被索引引用的临时 ID，清理使用已持锁的内部实现，不再次排入同一队列。原生写入若提交后报错，按读回结果判定；结果不确定时保留密文、报告错误，允许重试。
4. 只带元数据的重复调用若发现新 ID 有密文，必须提供密码证明才能合并清理，避免遗留调用继续误删。

普通私钥/助记词导入与开户保存两个调用点均传入当前密码。开户保存一旦尝试持久化，失败时保留可能已被索引引用的密文及原 pending 恢复材料；持久化之前取消仍清理新孤儿槽。页面收到失败不报告成功，不切换账户。

没有放宽链上账户权限核验、签名或系统认证保护。此处只修复重新导入顺序与所需的秘密队列事务，不声称钱包索引的全部并发问题已解决；`removeWallet`、普通列表去重及其他设备导入仍需按剩余覆盖清单审查。

## 回归与验证

新增 `vaultReimport.test.ts` 使用真实 PBKDF2/AES-GCM 和生成的无资金 K1 密钥（原生 PBKDF2 转发 Node crypto，SecureStore 为内存 Map）。旧源码对照覆盖旧槽缺失、损坏、错误私钥，分别在历史默认代次与已轮换代次运行。以存活索引的解密结果为判据，不把 API 正常返回当作修复证据。

另覆盖正常重复/助记词来源、首次加密导入、多个历史重复项、已有异常密文的拒绝与完整保留、当前密码证明、公钥一致性、密码轮换交错、写入失败、提交后报错、未知提交结果保留、副本清理失败和跨链记录。屏幕测试检查密码传入、失败时不报告成功、开户失败保留可能已提交的密文，保留其他既有安全断言。

最终有效运行 `validation-2`：旧源码 6 项行为对照如预期失败（缺槽无法解锁 2 项，异常旧槽错误返回成功 4 项）；最终实现 5 个定向套件、118 项通过。全量 Jest 103 个套件、1046 项通过；工具链测试 40 项通过、5 项按平台条件跳过、0 失败。TypeScript、依赖策略/补丁和注册表来源签名通过（invalid/missing 为空）。Expo 使用 SDK 自带离线映射检查通过，日志明确标注离线可靠性限制，不称为在线全量兼容验收。第一轮候选已通过全套验证，但复核后收紧异常旧槽处理：不覆盖无法验证的旧密文，新增首次导入和多个历史重复项的覆盖，最终以第二轮完整检查为准；第一轮日志保留，不能替代最终版本验证。对照前按 `before-manifest.json` 验证旧模块 SHA-256，使用同批来源签名检查通过的依赖，旧源码运行后恢复最终源码，再执行定向和全套验证；上轮 1024 项通过不作为本补丁验证结果。

沿用项目隔离 worker：固定镜像摘要、非 root、只读根、无宿主凭据、禁用依赖安装脚本，执行依赖策略、补丁和注册表来源签名检查；项目代码执行断网。NAS 的来源检查通过只允许 npm/Sigstore 两个公开目标的临时 HTTPS CONNECT 通道，保持端到端 TLS，未绕过签名、隔离或 Hermes 自身的运行时拒绝。无依赖/锁文件/策略哈希变更。

证据目录：`exports/reimport-security-2026-10-18/`。未运行原生真机 Keystore、未构建/签名/发布安装包；内存存储适配器不能证明所有原生存储行为。本补丁无法重建没有任何备份的历史丢失私钥。
