# 观察钱包与 TokenPocket 冷钱包签名

观察账户可以在联网的 EOS³ 钱包查看交易、生成 TP 待签二维码，再扫描离线 TP 冷钱包返回的签名结果。联网设备不导入冷钱包私钥，签名结果核验后才继续原来的广播或 DApp 回包流程。

## 使用流程

1. 在联网设备导入观察账户，保留相同的链和账户。
2. 在转账、资源与 REX 页面，或 DApp 的交易签名界面发起操作。
3. 核对本机交易确认页的合约、action、参数、账户、权限与来源，点击冷钱包扫码签名。
4. 若权限下存在多把能独立签名的公钥，选择 TP 冷钱包持有的那一把。
5. 用另一台离线设备的 TP 冷钱包扫描请求，核对交易后签名。
6. 回到 EOS³，点击扫描签名结果，扫描 TP 显示的返回二维码。也提供主动复制请求和粘贴结果入口。
7. 本机核验签名、公钥、原始交易和最新链上权限。普通转账由原有交易流程广播；DApp 只签名请求仅返回签名，不替 DApp 广播。

冷钱包设备在上述过程中保持离线。联网的是观察钱包设备，用于读取链数据、核验权限和广播。扫码失败可重试；取消、切换账户或节点、进入后台、交易过期都会使当前请求失效。

## 支持范围

- TP EOSIO 扫码协议 v1：生成 `eosio:signTransaction-version=1.0` 请求，接收 `eosio:signTransactionSignature-version=1.0` 返回；兼容返回完整已签交易 JSON 的形式。
- 当前账户的直接公钥必须单独达到所声明权限的阈值。可选公钥来自至少两个内置节点一致的实时权限数据，不接受网页提供的公钥作为信任依据。
- 支持常规转账、资源和 REX 操作，以及 DApp 的 action 交易、预序列化交易和 ESR 交易请求。观察账户默认声明 active；DApp 交易明确声明的权限继续按确认页展示的实际权限处理。
- 本机新构建的外部签名交易使用五分钟有效期。网站已经构建的交易保留它原有的过期时间与 TAPOS 字节，不自动延长、不自动重签。
- 小请求使用单张二维码，较大的请求按 TP 动态二维码协议分片轮播；签名回包也支持乱序拼接、去重和 CRC32 完整性检查。单个完整载荷上限为 64 KiB，最多 128 片，超过上限会明确提示减少操作。

暂不支持多签聚合、嵌套账户授权、任意消息签名、ESR 身份证明或 Sponsor 资源代付签名流程。资源不足时需先补充资源。只读查看、安全设置和本机密钥管理继续沿用原有行为，不会因观察账户可发起外部签名而获得本机密钥。

本次只新增 TP 的离线通道。原有 Anchor 登录和签名功能保留；没有新增 Anchor 手机冷签名或回调连接。

## 签名结果校验

签名前保存交易字节的独立副本。请求二维码包含完整交易和预期公钥，不向冷钱包发送单独摘要来代替交易。返回结果如包含交易或 packed_trx，必须与原始交易字节一致；如包含链、账户、公钥等元数据，也必须一致。

无论返回结果是否包含完整交易，签名始终针对本机原始交易与选定链的摘要验证，并使用已核实的公钥验签。签名验证后再次读取最新权限，确认该公钥仍能独立满足本次权限阈值。实际广播只使用原始交易及核验通过的签名，不使用二维码提供的新交易内容。

全局只允许一个待处理请求。请求 ID、原始交易、公钥和原生请求生命周期共同约束结果；旧二维码不能完成另一个待签请求。交易解码、过期时间、不可见字段、链检查、DApp 连接和用户确认的原有防护继续生效。

交易和扫码结果仅存在于本次会话内存中。关闭请求会撤销权限读取、清除计时器并移除弹层。不自动写剪贴板、不保存二维码或签名到钱包存储、不建立冷钱包回传服务器连接。

## 实现位置

| 文件 | 职责 |
| --- | --- |
| `src/chain/transactionWallet.ts` | 为当前观察账户创建内存中的无密钥签名身份，不改变 vault 或观察钱包列表 |
| `src/chain/signers.ts` | 观察账户返回外部签名者，不读取本机秘密 |
| `src/chain/walletPluginCold.ts` | 将 WharfKit Session 已确定的交易交给扫码流程 |
| `src/chain/coldSigningProtocol.ts` | TP 请求编码、返回格式解析及原始交易验签 |
| `src/chain/tokenPocketQr.ts` | TP 动态二维码分片、拼接、去重、大小限制与 CRC32 检查 |
| `src/chain/coldSigning.ts` | 请求互斥、权限核验、取消、过期和结果交付 |
| `src/components/ColdSigningHost.tsx` | 复用现有弹层与相机组件展示请求、扫码结果和重试 |
