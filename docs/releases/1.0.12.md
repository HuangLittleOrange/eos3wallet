# EOS³ Wallet 1.0.12

iOS 与 Android 修复版本。Android 版本码 13；iOS 使用递增构建号 37，沿用 GitHub Actions 编译、独立签名和 TestFlight 上传流程。

- 修复导入观察钱包后切换到其他钱包，重启应用时观察钱包丢失的问题。观察钱包现在持久保存到账户列表，切换钱包或网络、重启应用后仍可选择。
- 保存的观察钱包继续显示只读状态，不保存私钥或创建主密码。重复导入同一网络的同一观察账户会合并记录；不同网络分别保存。
- 保存完成后才进入钱包页；保存失败时提示重试，保存期间避免重复提交。
- 移除观察钱包后，切换网络或重启应用不会恢复已删除的记录。
- 修复旧版观察钱包移除后直接进入无钱包引导页的问题：仍有当前网络的钱包时自动选中剩余钱包，再返回资产首页。
- 移除创建钱包页的“Anchor 一键开户”和导入页的“通过 Anchor 授权”入口。

此前已经被旧会话覆盖而消失的观察钱包，需要更新后重新导入。
