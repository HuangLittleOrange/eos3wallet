# EOS³ Wallet 1.0.8

iOS 与 Android 完整安装包，Android 版本码 6，沿用现有发行签名。热更新保持关闭。

- 密码、私钥和助记词输入框统一禁用系统自动填充，避免导入材料被系统识别为登录用户名并保存。
- 首次设置密码、修改密码、交易签名、导入确认、生物识别开启验证及私钥导出验证均使用同一套设置。
- 显示密码明文时继续禁用自动填充；关闭自动纠错、拼写检查和智能插入删除。
- 保留通行密钥登录所需的关联域名及现有加密存储流程。
- 包含 1.0.7 的 RAM / PowerUp 自动恢复、完整预计总费用和安全中心修改密码功能。

系统“密码”应用里已经保存的旧记录需要由用户手动删除。组件回归测试无法代替 iOS / Android 真机系统保存提示验证。

iOS 通过 Expo EAS 构建内部 Ad Hoc 包；Android 沿用 GitHub Actions 版本标签构建、固定证书签名及来源证明流程。
