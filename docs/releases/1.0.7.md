# EOS³ Wallet 1.0.7

iOS 版本，包标识 `com.eos3.wallet`，沿用现有 Ad Hoc 签名。构建号由 EAS 自动递增，热更新保持关闭。

- RAM 不足时显示包含链上手续费的预计总费用，确认后购买约 1KB RAM；不收 RAM 钱包服务费。
- CPU/NET 同时不足时，先购买 PowerUp，再自动购买 RAM；RAM 失败可单独重试，避免重复购买 PowerUp。
- RAM 按链上实际成交价扣款，价格上涨不再确认；费用明细合并为总费用。
- 安全中心新增“修改密码”，支持验证旧密码并重新加密本机钱包及待导入设备密钥。全部新密文校验成功后统一切换。
- 修改密码后关闭旧生物识别凭据，可在安全中心重新开启。
- 安全中心移除助记词/私钥备份和使用统计入口，保留旧版已关闭的统计偏好。

本次仅构建 iOS 安装包，不自动提交 TestFlight、App Store 或修改线上更新配置。
