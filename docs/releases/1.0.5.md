# EOS³ Wallet 1.0.5

本次通过 Expo 内测渠道分发 iOS 完整安装包，通过公开 GitHub 构建和 Release 分发 Android 完整安装包；热更新保持关闭。Android 版本码为 4，沿用既有正式签名证书，支持覆盖升级。

更新说明：

- 打开账号列表时整批更新权限标识。
- 切换账号立即切换代币、资源和授权列表，避免旧账号数据短暂显示。
- RPC 和历史节点不可用时自动切换到同链可用节点。
- 启动时检查完整安装包更新，并保留手动检查入口。
- 支持 Anchor Passkey 网页授权导入手机钱包。

后台发布策略：iOS 和 Android 均发布普通更新，允许稍后；强制更新关闭，最低支持版本码为 0。各平台安装地址以实际构建、验签通过的安装包为准。
