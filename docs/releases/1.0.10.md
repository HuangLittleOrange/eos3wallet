# EOS³ Wallet 1.0.10

应用版本 1.0.10，Android 版本码 11。本次准备源码版本，正式安装包仍通过既有版本标签构建和签名流程发布；热更新保持关闭。

- 观察账户支持通过离线 TP 冷钱包完成转账及其他受支持交易的扫码签名，联网设备只持有观察账户。
- 降低动态二维码每帧数据密度，解决较大请求在 TP 扫码时停在 75% 的问题，保留 64 KiB 完整载荷限制。
- 修复 Android 首次相机权限弹窗中断冷签名，以及旧请求的异步扫码、剪贴板或权限回调影响新请求的问题。
- 观察账户导入拒绝全点空账户名，并规范化尾随点；钱包列表新增通往网络管理的入口。
- 补充动态二维码、真实 TP 公共签名样本、权限弹窗与旧请求隔离的回归测试。

本地使用真实 Jungle4 测试账户和 TP 2.29.0 完成四帧请求、离线签名、EOS³ 原生相机连续收齐 13 帧及独立验签。测试入口在 HTTP 发出前拦截转账广播，签名前后余额均为 100 测试 EOS。测试在安卓模拟器完成，未验证本轮转账上链执行。
