# EOS³ Wallet 1.0.13

iOS 与 Android 修复版本。Android 版本码 14；iOS 使用递增构建号 38，沿用 GitHub Actions 编译、独立签名和 TestFlight 上传流程。

- 私钥复制成功后，关闭导出弹窗、切换到其他 APP 或离开页面均不再清空系统剪贴板，可以继续粘贴到其他 APP。使用完毕请自行清除剪贴板。
- 切后台再返回时保留已打开的私钥明文弹窗，无需重复解锁；手动关闭弹窗、切换钱包或离开页面时清除明文展示。
- 保留截屏保护及 iOS 应用切换界面的模糊遮挡。
- 切后台时仍取消尚未完成的复制，清理晚到的剪贴板写入；后台不执行新的私钥复制，失败时不显示复制成功。

回归覆盖跨 APP 粘贴所需的剪贴板保留、多次切后台后保留明文展示、手动关闭、切换钱包、离开页面，以及未完成复制的取消和返回前台后的重试。
