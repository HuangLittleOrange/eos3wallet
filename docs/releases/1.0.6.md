# EOS³ Wallet 1.0.6

Android 完整安装包，版本码 5，沿用原正式签名证书。热更新保持关闭。

- 修复 Anchor Passkey 验证后返回手机钱包时，网络中断导致导入失败的问题。
- 等待钱包恢复前台再继续请求，RPC 不可用时自动切换到同链可用节点。
- 补齐同设备 ESR 返回路径；回到钱包后恢复已缓冲的 Anchor 回调，避免成功验证被当成取消。
- 连接失败保留 Anchor 登录会话和本机密钥，可重试继续导入。
- 签名广播只提交一次；响应丢失后需检查链上授权或重新核对交易。
- 退出导入页会取消等待和请求，阻止迟到的权限校验结果写入钱包。

验签和来源核验通过后发布 Android 普通更新，允许稍后；不启用强制更新，最低支持版本码为 0。iOS 继续保留已发布的 1.0.5（29）配置。
