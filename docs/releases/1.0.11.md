# EOS³ Wallet 1.0.11

iOS 修复版本，沿用 GitHub Actions 编译、独立签名和 TestFlight 上传流程，构建号 36。Android 版本码保持 11，本次不发布 Android 安装包。热更新保持关闭。

- 私钥导入统一清理复制时夹带的空格、换行和零宽分隔符，兼容旧版 `5…` WIF 与 `PVT_K1_…` 格式；仍严格检查密钥格式和校验和。
- 私钥与助记词导入页面在切换应用后保留当前输入，退出页面后不再保留。进入后台时取消未完成的账户查找和导入确认，回来后重新查找并确认。
- 保留截屏保护及 iOS 应用切换界面的模糊遮挡。
- 本地主密码和导入输入使用非登录凭据的 iOS 内容类型，处理确认导入后系统误提示保存网站密码的问题。保留密码遮蔽；系统可能仍提供验证码候选，是否消除保存提示需在新包上真机复核。
- 钱包详情页为观察账户新增“移除观察钱包”按钮，确认后清除本机观察记录，切链或重启不再恢复已移除的观察账户；保留其他钱包及链上资产。

回归覆盖旧版 WIF、粘贴字符清理、错误校验和、切换应用后继续填写、退出后重新进入、后台取消导入及既有账户身份核验。
