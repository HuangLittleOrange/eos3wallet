# EOS³ Wallet 1.0.9

Android 完整安装包，版本码 10，沿用现有正式签名证书和完整目标架构。热更新保持关闭。

- 创建钱包新增“Anchor 一键开户”，复用已有 Anchor 网页设备授权流程。
- Google 开户改为前往 eos3.app 完成登录、开户和设备授权，App 不再直接发起原生 Passkey 注册或登录。
- 修复 Android 在 Anchor 网页登录后不能自动返回钱包的问题：授权期间使用短时前台连接任务，成功、取消、异常或超时后关闭。
- 授权回跳保留原开户或导入页面状态，避免开户过程中切换为导入页面。
- 本机设备私钥继续加密保存；账户连接后需核对设备授权交易，完成后独立检查链上权限，不以登录回调作为授权成功依据。

Android 1.0.8（9）测试包已在既有 Android 15 模拟器验证：网页停留超过 35 秒后完成真实 Anchor 登录，自动返回开户页面并进入设备授权审查，连接任务随即停止；取消登录也正常停止任务。未在这轮验证中确认或提交链上授权交易。

正式 APK 沿用公开 GitHub Actions 版本标签构建、固定证书签名及来源证明流程；正式包的构建、签名和核验结果记录在对应 Release。iOS 不在本次打包范围。
