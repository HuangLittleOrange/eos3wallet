# EOS3 Wallet 1.0.15

- Add custom EOSIO / Antelope networks with RPC chain-ID verification, local persistence, and separate wallet sessions.
- Show mainnets and testnets in one network list, with an Add custom network entry.
- Simplify Discover by removing its network header and switch entry.
- Remove the browser translation shortcut and unavailable account, authorization, REX, export, and explorer entries for unsupported networks or wallet types.
- Remove the unavailable service-agreement link from contract account creation.

Custom networks support account observation with one HTTPS RPC. Private-key imports and signing retain two-host verification and require an independent backup RPC configured when adding the network. EOS3 web account creation and managed authorizations remain available on Vaulta only.

Validation: 131 application test suites, 1,397 tests; TypeScript, source, and dependency checks passed locally. Native builds and platform release checks run separately in GitHub Actions.
