# 绑定安全说明

绑定页面支持受限支付授权。用户确认的代币和额度必须对应实际链上配置，应用不能获得绕过限额合约直接转账的权限。

## 校验规则

- 核对账户、网络和应用身份，拒绝预览后发生的替换。
- 验证转账权限只能由指定限额合约使用，不能添加直接转账的第三方密钥。
- 逐项比较代币、精度、单笔额度、每日额度和总预算，拒绝遗漏、增加、重复或放宽配置。
- 零值表示该项限制未启用，页面显示为“不限”；每日和总预算至少设置一项。
- 检查已有链上权限和额度，移除同一应用未被用户选中的旧代币配置。
- 拒绝额外的通用合约操作和无法识别的权限变更。

客户端根据确认内容重建操作并固定交易。确认页面和签名使用同一份内容；签名前再次检查链上状态。切换钱包或网络、查询失败或无法完整验证时停止提交。

## 支持范围

支持首次支付绑定及符合校验规则的重新绑定。申请支付之外的合约操作，需要独立的授权流程和明确的操作范围说明，不在本页面混合授权。

校验依赖所选节点提供正确数据，以及指定限额合约保持可信。客户端更新不会自动撤销其它途径已经授予的权限。

实现见 [bindIntent.ts](../src/chain/bindIntent.ts) 和 [bindAuthorize.ts](../src/chain/bindAuthorize.ts)。
